- [ ] Secrets 管理、模型供应商数据授权和留存政策；
- [ ] SLO/告警、trace、结构化日志、异常原因与运行手册；
- [ ] 法务和工程对外使用说明、免责声明和合规边界；

## Gate
系统只有在真实授权语料、工程领域审核、安全/恢复/容量测试通过后才可声称生产可用。SHACL 零违规、RAG 命中率或演示成功**均不等于**汽车功能安全合规。
