# v1.0 Stage 1 验收报告（候选抽取 MVP）

> 验收范围：公开仓库中的合成测试 PDF，不是实际车厂式样、功能安全认证或大规模 Benchmark。

## 已验证流水线

`PyMuPDF PDF → Page/Block/BBox → deterministic normative Candidate → ontology contract validator → PostgreSQL / SQLite → authenticated API → source evidence and original PDF`

- 代码：`src/auto_ontology/parser.py`、`extractor.py`、`validation.py`、`service.py`、`db.py`、`api.py`、`cli.py`。
- Schema：`src/auto_ontology/schemas/automotive.yaml`，强制 candidate-only。
- 合成资料：`tests/conftest.py` 用 PyMuPDF 动态生成 PDF，不保存真实 OEM 文档。
- 运行说明：[v1.0 Runbook](v1.0-runbook.md)。

## 不构成通过的部分

| 未完成 | 原因 |
|---|---|
| 真实 Docling Graph 解析 | 当前用 PyMuPDF blocks，而非 Docling 复杂布局能力 |
| LLM/LinkML 需求原子化 | 当前 deterministic regex，未使用真实抽取模型 |
| 工程语义正确率 | 无经过工程专家盲标 Gold Set |
| DBC/Signal/ECU、跨文档关系 | 属 Stage 2 |
| 审批后的正式知识 ABox | candidate-only，不提供 publish |
| 企业级鉴权和加密 | 只有单开发 API Key |
| 性能/恢复/部署 SLA | CI 只测试小型样本 |
| 全链路交互 UI | 只有 CLI / OpenAPI / HTTP JSON |

**判定：v1.0 Stage 1 可运行基础切片通过基础 CI Gate；完整 Stage 1 和工业化 Gate 未通过。**
