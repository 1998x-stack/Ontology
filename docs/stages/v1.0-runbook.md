# v1.0 本地运行手册（Stage 1）

> 本阶段是 candidate-only 的单 key 演示服务，不适合在生产公网开放或存储未获授权的 OEM 文档。

## 安装

```bash
git checkout v1.0
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m pytest -q
```

## CLI

```bash
ontology --db sqlite:///./ontology.db ingest example.pdf --project DEMO --code SPEC-573 --revision 2.1
ontology --db sqlite:///./ontology.db list --project DEMO
```

## 启动 API

```bash
export ONTOLOGY_API_KEY='set-a-local-development-secret'
export DATABASE_URL='sqlite:///./ontology.db'
ontology serve
```

健康检查：`GET http://127.0.0.1:8000/health`（无认证）。其他 `/api/v1/*` 接口均需 `X-API-Key`。

```bash
curl -H "X-API-Key: $ONTOLOGY_API_KEY" \
  -F "project_id=DEMO" -F "document_code=SPEC-573" \
  -F "revision=2.1" -F "file=@example.pdf" \
  http://127.0.0.1:8000/api/v1/documents
```

已认证的 GET /api/v1/documents/{id}/source 可回读原始 PDF，用返回的 page_no 与 bbox 定位证据；响应禁止缓存。当前只有单一 API Key，尚不适合多租户。

之后可使用 `GET /api/v1/documents/{id}/candidates` 与 `GET /api/v1/anchors/{id}` 查看候选与原文锚点。

## PostgreSQL（需可用驱动）

```bash
python -m pip install -e '.[postgres,dev]'
export POSTGRES_PASSWORD='local-only-secret'
docker compose up -d postgres
export DATABASE_URL="postgresql+psycopg://ontology:$POSTGRES_PASSWORD@localhost:5432/ontology"
export ONTOLOGY_API_KEY='local-only-api-key'
ontology serve
```

本阶段 PostgreSQL 只说明连接路径，不代表已执行 PostgreSQL 集成测试、生产迁移或数据权限隔离。

## 非目标与已知限制

- 并非 Docling Graph/LLM，当前仅 PyMuPDF + 保守 regex baseline；
- 不能准确解析跨页表格、条件继承、日文复杂式样和状态图；
- 不提供审核发布、版本 diff、Neo4j 或正式 TestCase；
- 单个 API key 只适用独立开发环境，尚无租户级、项目级、锚点级 ACL；
- 上传最多 15 MiB、100 页、12k 文本块、200 万字符；原始 PDF 存为数据库二进制；
- Python SQLAlchemy `create_all` 只适合初始原型，生产必须 Alembic migration；
- CLI 需本地文件可读，API 拒绝空 key，日志中不得显示原文和凭据。

## 安全和合规

禁止把真实客户式样书、CAN 定义、密钥提交到公开 GitHub；上传受许可限制的文档前应先确认保存与模型处理政策。本阶段不调用外部 LLM。
